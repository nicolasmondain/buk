# Encres

> Statut : seed. Voir `SOURCES.md` pour ce qui est confirmé par la recherche vidéo.

## Les trois encres de buk

| Encre | Usage | Exigences |
|---|---|---|
| **Noir de lining** | Traits | Noir dense qui ne file pas ; certains utilisent le même noir pour tout |
| **Noir de remplissage** | Whip, noir plein | Très pigmenté, couvrant |
| **Rouge** | Aplats rouges | Conforme REACH, lot noté ; c'est la couleur la plus allergisante |
| **Blanc** | Rehauts | Blanc opaque épais ; posé en dernier |

Pas de gris lavé dans le style buk : l'ombrage est fait **au geste** (whip) avec le noir pur.
Option tolérée si la personne insiste : une seule dilution claire de noir pour adoucir un whip,
mais ce n'est plus du strict old school.

## Préparation

1. Agiter les flacons (le pigment se dépose) ; une bille dans le flacon aide.
2. Capsules posées sur le film barrière, fixées avec un point de vaseline.
3. Une capsule de noir pour les traits, une pour le remplissage, une pour le rouge, une petite pour
   le blanc, un gobelet d'eau (ou eau + savon) pour rincer.
4. Quantité : remplir au tiers ou à moitié ; on rajoute plutôt que jeter.

## Ordre des couleurs

1. Noir (traits) → noir (whip) → noir plein.
2. **Rouge**, avec une cartouche dédiée (ou rincer à fond jusqu'à ce que l'eau sorte claire).
3. **Blanc** en tout dernier, toujours avec une cartouche dédiée et propre.

On va du plus sombre au plus clair pour éviter de salir les couleurs claires ; essuyer
régulièrement l'excès de noir pour ne pas le pousser dans le rouge.

## Rincer entre deux encres

Plonger la pointe dans l'eau, machine en marche, jusqu'à ce que l'eau ressorte sans pigment ; puis
« vider » la cartouche sur un sopalin. Au moindre doute pour le rouge et le blanc : cartouche neuve.

## Conservation

Flacons fermés, à l'abri de la lumière et de la chaleur ; respecter la date de péremption et la
durée après ouverture. Une encre épaissie ou séparée qui ne se remélange pas est jetée.
